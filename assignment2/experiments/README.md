# Student experiments and regressions

Run from `assignment2/` using the environment in [SETUP.md](../SETUP.md).
No additional student files belong in the TA `src/` or `tests/` folders.

```bash
venv/bin/python -m pytest experiments -q
venv/bin/python experiments/step8_phase_e.py --verify-fit
```

`test_kinematics.py` consolidates Phase A–C model, residual/fit and rank tests.
`test_calibration.py` consolidates Phase D/E and bound-diagnostic regressions,
including an independent quadratic-bound oracle. `test_ik_robustness.py` retains
live/replay parity and the failure evidence. Earlier metric, registration,
workflow and planning regressions are also here. `conftest.py` supplies the
assignment import root; `../pytest.ini` discovers both official and student tests.

Only three experiment drivers remain:

- `step8_phase_d.py`: original acquisition provenance, historical unconstrained
  fit, sweep plots, and independent bound/covariance comparison (`--bounds`).
  `--analyze-only` uses archives. The default can acquire data if archives are
  missing and can overwrite historical results; it is not the routine check.
- `step8_phase_e.py`: constrained fit/report/IK audit. `--verify-fit` checks the
  default fitter with saved data without changing archives. The full default
  reruns cold/warm fits and replaces Phase E evidence; `--audit-only` reuses fits.
- `ik_robustness_diagnostic.py`: instrumented experimental IK ablations, not a
  replacement for the protected production inverse. It only reuses saved data.

The superseded standalone bound-diagnostic driver and duplicate SLSQP solver
were removed. `step8_phase_d.py --bounds` now delegates fitting to the production
implementation in [vendor/functions](../vendor/functions/_fit_constraints.py),
using a separate candidate model, and retains independent extrema/covariance
calculations. Historical diagnostic values stay unchanged in [results](../results/README.md).
No archived measurements are regenerated by the regression tests or `--verify-fit`.

The original TA test files remain under `tests/`. The full suite includes the
pre-existing unimplemented marker-refinement failure; student tests retain three
strict expected failures for the unchanged TA inverse. No original assertions
have been weakened. Do not start Steps 9–10 as part of these checks.
